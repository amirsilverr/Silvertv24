OMDb API Settings

Poster Database

Add your OMDb API key to load series poster images beside titles throughout the lists.

How to get your free API key

  1. Open the OMDb API Key page.
  2. Select FREE! (1,000 daily limit).
  3. Enter your email, name and a short description of your project, then submit.
  4. Open the email from OMDb and follow its activation link. Copy the API key from that email.
  5. Return here, press Edit, paste the key and press Save.

Free plan limit: 1,000 requests per day. Poster lookup is cached in this browser to reduce repeat requests.

Privacy note: This is a front-end HTML app. The key is stored in this browser and can be seen by anyone who can inspect the page or browser requests. Do not use a private production key here if the website is public; a server-side API route is safer.
